Code & Quest

Learn React through a game-inspired coding adventure.

Code & Quest is an interactive, browser-based educational game developed for the Gamification Innovation Lab at OWL University of Applied Sciences and Arts (TH OWL). It teaches React fundamentals through guided lessons, hands-on coding challenges, and game-style progression.

Features

• Interactive lessons covering React components, props, state, and other fundamentals

• Built-in code editor with a live preview of the results

• Feedback on completed coding challenges

• Game-style progression featuring quests, learning areas, and boss challenges

• Progress saved locally in the browser

• No account or sign-in required

Technologies

React 18, ReactDOM, JavaScript, HTML, CSS, Babel Standalone, browser localStorage, and GitHub Pages

Running Locally

1. Clone the repository:

git clone https://github.com/MackKeim/Code-And-Quest.git

cd Code-And-Quest

2. Start a local web server:

python -m http.server 8000

3. Open http://localhost:8000 in your browser.

The project runs directly in the browser without requiring an npm build process. An internet connection may be necessary to load external libraries.

Project Background

Code & Quest was developed as a team university project for the Gamification Innovation Lab at TH OWL.

Mack Keim served as a project lead alongside team members Farzad Taghinia, Nima Kalhori, Wei Chen Chin, and Zain ul Abdin Khoso.

The project demonstrates frontend development, interactive learning, user interface design, and the application of gamification principles to programming education.

This is an educational prototype rather than a commercial learning platform.
