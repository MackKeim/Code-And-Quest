Code & Quest

Learn React through an interactive, game-inspired coding adventure.

Code & Quest is a browser-based educational project developed for the Gamification Innovation Lab at OWL University of Applied Sciences and Arts (TH OWL).

The project combines programming lessons, interactive coding challenges, and game-style progression to introduce users to React development in an engaging way.

Features

- Interactive lessons introducing React fundamentals, including components and props
- Browser-based code editor with a live preview
- Coding exercises with answer validation and feedback
- Game-style progression with quests, rewards, and boss challenges
- Progress tracking using browser localStorage
- No account or sign-in required

Technologies

- React and ReactDOM
- JavaScript, HTML, and CSS
- Babel Standalone for processing JSX
- Browser localStorage for saving progress
- Static web hosting compatible with GitHub Pages

Running Locally

1. Clone the repository:

git clone https://github.com/MackKeim/Code-And-Quest.git

2. Open the project directory:

cd Code-And-Quest

3. Start a local web server:

python -m http.server 8000

4. Open http://localhost:8000 in your browser.

The static version does not require an npm build process. Some external libraries may require an internet connection.

How It Works

Users progress through programming lessons and challenges by writing and testing code directly in the browser.

The integrated preview allows learners to see the results of their code, while exercise feedback helps guide their progress.

Completed activities contribute to the game's progression, with progress stored locally in the browser.

Project Background

Code & Quest was developed as a university team project for the Gamification Innovation Lab at TH OWL.

Mack Keim served as a project lead alongside Farzad Taghinia, Nima Kalhori, Wei Chen Chin, and Zain ul Abdin Khoso.

The project explores frontend development, user interface design, interactive learning, and the application of gamification concepts to programming education.

Project Status

Code & Quest is an educational prototype rather than a commercial learning platform. Some planned features may remain incomplete or subject to further development.
